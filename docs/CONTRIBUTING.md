# Guide de Contribution

Merci de vouloir contribuer à Aristech ! Ce guide vous aidera à faire des contributions de manière efficace et organisée.

## Processus de Contribution

1. **Fork le dépôt** : Créez une copie du dépôt sur votre propre compte GitHub.
2. **Clonez votre fork** :
    ```bash
    git clone https://github.com/votre-utilisateur/aristech.git
    cd aristech
    ```
3. **Créez une branche pour votre fonctionnalité** :
    ```bash
    git checkout -b nouvelle-fonctionnalite

4. **Développez et commitez vos changements** :
    ```bash
    git add .
    git commit -m "Ajout de la nouvelle fonctionnalité"
    ```
5. **Poussez votre branche vers GitHub** :
    ```bash
    git push origin nouvelle-fonctionnalite
    ```
6. **Créez une pull request** : Ouvrez une pull request sur le dépôt original pour examiner vos modifications.

## Style de Codage

- Utilisez des commentaires clairs et concis.
- Suivez les conventions PEP 8 pour Python.
- Écrivez des tests unitaires pour toute nouvelle fonctionnalité.

## Rapport de Bug

Si vous trouvez un bug, veuillez ouvrir une issue sur GitHub en fournissant autant de détails que possible :
- Version du logiciel
- Système d'exploitation
- Étapes pour reproduire le bug
- Comportement attendu
- Comportement actuel

## Demandes de Fonctionnalité

Si vous avez une idée pour une nouvelle fonctionnalité, veuillez ouvrir une issue sur GitHub en décrivant :
- Le problème que la fonctionnalité résoudrait
- Une description claire et concise de la fonctionnalité
- Toute alternative que vous avez envisagée
- Des exemples d'utilisation si possible

## Règles de Conduite

Nous nous engageons à fournir un environnement de collaboration ouvert et accueillant. En contribuant à ce projet, vous acceptez de respecter notre code de conduite. Nous vous demandons de :
- Être respectueux et courtois envers les autres contributeurs
- Fournir des commentaires constructifs et encourageants
- Faire preuve d'empathie et de bienveillance

Pour plus de détails, veuillez lire notre [Code de Conduite](CODE_OF_CONDUCT.md).

Merci de contribuer à Aristech !
