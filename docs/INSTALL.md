# Instructions d'Installation pour Aristech

## Prérequis

- Python 3.8 ou supérieur
- pip

## Étapes

1. Clonez le dépôt GitHub :
    ```bash
    git clone https://github.com/votre-utilisateur/aristech.git
    cd aristech
    ```

2. Installez les dépendances :
    ```bash
    pip install -r requirements.txt
    ```

3. Modifiez les fichiers de configuration pour adapter le système à votre environnement :
    - `config/config.yaml`
    - `config/logging.yaml`

## Configuration

1. Ouvrez et modifiez les fichiers de configuration suivants :
    - `config/config.yaml`
    - `config/logging.yaml`

2. Assurez-vous que tous les chemins et paramètres sont correctement définis pour votre environnement.
