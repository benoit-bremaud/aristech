# UML diagrams

Mermaid, UML 2.5. One folder per feature: `<feature>/NN-<type>.md`, where `<type>` is one of
`use-case`, `sequence`, `component`, `class`, `state`, `data-flow`, `activity`.

Use cases are actor-initiated goals, never system events, and are grouped by domain, not by the
component that implements them.
