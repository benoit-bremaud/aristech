# Bill of Materials (BOM) pour Aristech

## Composants Électroniques

1. **Microcontrôleur** :
   - Raspberry Pi 4
   - Alternatives : Teensy 4.1, Esp8266 DevKitC, Esp32 DevKitC-VIE

2. **Capteurs** :
   - Microphone MEMS
   - Caméra haute résolution (e.g., Raspberry Pi Camera Module)
   - Capteurs ToF (Time-of-Flight)
   - Modules stéréo caméra

3. **Modules de Communication** :
   - Module LoRaWAN (e.g., RAK Wireless)
   - Module Bluetooth/WiFi (intégré dans certains microcontrôleurs)

4. **Autres Composants** :
   - Actionneurs mécaniques pour SOLAR
   - Connecteurs et câblage
   - Châssis de protection et support pour panneaux solaires

## Outils Nécessaires

- Fer à souder et consommables
- Multimètre numérique
- Tournevis, pinces, et autres outils de montage
