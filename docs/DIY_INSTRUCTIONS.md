# Instructions DIY pour Aristech

Ce guide vous permettra de construire et de paramétrer votre propre dispositif Aristech pour la détection et la neutralisation des frelons asiatiques.

## Matériel Nécessaire

- Composants électroniques (listés dans `BOM.md`)
- Outils de soudure
- Capteurs et caméras spécifiques
- Châssis et boîtier de protection

## Étapes de Construction

1. **Assemblage des Composants** :
   - Suivez les schémas fournis dans `docs/schematics/`.
   - Soudez les composants selon le guide.

2. **Installation du Logiciel** :
   - Clonez le dépôt GitHub et installez les dépendances comme décrit dans `docs/INSTALL.md`.

3. **Configuration** :
   - Modifiez les fichiers de configuration pour adapter le système à votre environnement.

4. **Tests et Calibration** :
   - Suivez les instructions dans `docs/calibration.md` pour calibrer les capteurs et les caméras.

5. **Mise en Service** :
   - Démarrez le système et vérifiez son fonctionnement.

Pour toute question ou assistance, veuillez consulter notre [FAQ](docs/faq.md) ou ouvrir une issue sur GitHub.
